Kebijakan Privasi

Terakhir diperbarui: Januari 2025

1. Informasi yang Kami Kumpulkan

Platform KANUM mengumpulkan data berikut saat Anda mendaftar dan menggunakan layanan:

  • Data akun: nama lengkap, alamat email, kelas/role.
  • Data aktivitas: hasil latihan, jawaban soal, skor, dan waktu pengerjaan.
  • Data teknis: jenis perangkat dan browser (tidak menyimpan alamat IP secara permanen).

2. Penggunaan Data

Data yang dikumpulkan digunakan untuk:

  • Menyediakan layanan pembelajaran yang personal.
  • Menghasilkan laporan progres belajar untuk guru dan siswa.
  • Mendukung tujuan penelitian akademik tentang efektivitas pembelajaran etnomatematika.
  • Meningkatkan kualitas platform KANUM.

3. Penyimpanan Data

Data disimpan di Supabase (platform cloud yang aman) dengan enkripsi standar industri. Data tidak dijual, disewakan, atau dibagikan kepada pihak ketiga komersial.

4. Hak Pengguna

  • Mengakses dan memperbarui data profil melalui halaman Pengaturan.
  • Meminta penghapusan akun dengan menghubungi administrator platform.

5. Keamanan Data

Platform menggunakan autentikasi terenkripsi (Supabase Auth), Row Level Security (RLS) di database, dan HTTPS untuk semua komunikasi. Kata sandi tidak pernah disimpan dalam bentuk teks biasa.

6. Kontak

Untuk pertanyaan terkait privasi data Anda, hubungi kami melalui halaman utama KANUM.
